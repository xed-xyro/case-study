JOEY'S RESTAURANT CAFE - UPDATED DIGITAL WIREFRAME

This low-fidelity HTML/CSS/JavaScript wireframe was updated using the supplied deployed website
(https://incredible-travesseiro-e2994b.netlify.app/) and the supplied html(1).zip source files.

PAGES
- index.html: Home page; welcome heading, quick links to Popular Meals / Specialties / Desserts / Drinks, four feature statements.
- menu.html: Menu page; View Menu category selector (12 categories), grouped menu items, menu search.
- about.html: About page; The Story text, restaurant image placeholder, Write a review modal, name/dish/rating/review fields, review list preview.
- contact.html: Contact page; telephone, Facebook, Gmail, and location rows.

SHARED FILES
- wireframe.css: grayscale layouts and responsive styling
- wireframe.js: mobile navigation, menu category selection/search, and local review-form preview

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in a current web browser.
3. Use the top navigation to move between pages.

WIREFRAME NOTES
- This is a structural wireframe and intentionally uses placeholder boxes instead of the production food photos,
  restaurant photo, and social/contact icons.
- Product names and menu category groupings follow the supplied site. The live menu source does not expose prices,
  so no prices have been invented or added.
- Submitting a review only adds a temporary preview card in this browser session; it is not connected to the
  production review database or the live website.
- The live Contact page lists 641 General Luna Street, while its footer lists 39 General Luna Street.
  This wireframe preserves the two locations in their corresponding areas rather than silently resolving the difference.
